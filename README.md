# HELLO WORLD

The goal of this project is to print to the console a line of text that says "Hello World."

## Instructions for Build and Use

Steps to build and/or run the software:

1. Make a class.
2. Inside the class, make a main function.
3. In side main, write Console.Write("Hello World");

Instructions for using the software:

1. Run the base program.
2. Look at the console to see the line of text.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* C# 14
* .NET 10
